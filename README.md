# Advanced Programming Course

A collection of programming assignments and exercises completed for the **Advanced Programming** course at the Computer Engineering Department of Iran University of Science and Technology, instructed by Dr. Rafiei.

## Overview

This repository contains implementations of programming concepts and assignments covering object-oriented programming, algorithmic problem-solving, and software development practices.

## Topics Covered

* Object-Oriented Programming (OOP)
* Classes and Objects
* Callback Functions and Automatic Execution
* Inheritance and Polymorphism
* Algorithm Implementation
* Problem Solving

## Course Information

* **University:** Iran University of Science and Technology
* **Faculty:** Computer Engineering
* **Course:** Advanced Programming
* **Instructor:** Dr. Rafiei
